## Как использовать в коде

- **Корабли и арсенал** — обычные png с альфой. Корабли нарисованы горизонтально, носом вправо; вертикальные — поворот на 90°.
- **Эффекты `fx/*.png` — слои «умножение»**: бумага в них выбелена до чистого белого. Рисовать с `mix-blend-mode: multiply` (CSS) или `ctx.globalCompositeOperation = 'multiply'` (canvas) — белое исчезает, остаётся рисунок.
- Раскадровки `*_stripN.png` — кадры в одну строку, ширина кадра = ширина / N.
